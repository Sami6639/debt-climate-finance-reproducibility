----------------------------------
CRS related-file information
----------------------------------

The CRS related-files << CRS [yyyy] data.txt >> have been created 
and saved as pipe (vertical bar ('|')(ASCII 124)) delimited text.

Fields are also encapsulated with double quotes ("")(ASCII 34).

Since September 2023, the related-files have been encoded in UTF-8.

Specify the above encoding when opening the file to ensure that all
accented characters appear correctly.

	- The CRS related-files now contain multilateral
